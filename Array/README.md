# 🚀 DSA - Array Fundamentals (Java)

This repository contains my solutions to fundamental Array problems in Java. The focus is on building a strong core in Data Structures and Algorithms, optimizing for time and space complexity, and mastering single-pass array traversals.

## 📁 Repository Contents

*   **`binarySearch.java`** - Implementation of the Binary Search algorithm to find an element in a sorted array efficiently ($O(\log N)$).
*   **`largestNumber.java`**[cite: 2] - Logic to traverse an array and find the maximum element.
*   **`linearSearch.java`**[cite: 2] - Implementation of Linear Search to find an element by checking each index sequentially ($O(N)$).
*   **`maxConsecutive1.java`**[cite: 2] - Solution to find the maximum number of consecutive 1s in an array by maintaining a running count.
*   **`secondLargest.java`**[cite: 2] - Optimal single-pass approach to find the second largest element in an array without relying on sorting.
