# 🚀 DSA - Array Fundamentals (Java)

This repository contains my solutions to fundamental Array problems in Java. The focus is on building a strong core in Data Structures and Algorithms, optimizing for time and space complexity, and mastering single-pass array traversals.

## 📁 Repository Contents

*   **`binarySearch.java`** - Implementation of the Binary Search algorithm to find an element in a sorted array efficiently ($O(\log N)$).
*   **`largestNumber.java`** - Logic to traverse an array and find the maximum element.
*   **`leftRotateByOne.java`** - Logic to shift all elements of the array to the left by exactly one position ($O(N)$ time, $O(1)$ space).
*   **`leftrotatebyk.java`** - Left rotation of an array by `k` steps, featuring both Brute Force ($O(K)$ space) and Optimal 3-Step Reverse ($O(1)$ space) approaches.
*   **`linearSearch.java`** - Implementation of Linear Search to find an element by checking each index sequentially ($O(N)$).
*   **`maxConsecutive1.java`** - Solution to find the maximum number of consecutive 1s in an array by maintaining a running count.
*   **`reverseArray.java`** - In-place array reversal using an optimal two-pointer approach ($O(N)$ time, $O(1)$ space).
*   **`secondLargest.java`** - Optimal single-pass approach to find the second largest element in an array without relying on sorting.

## 🛠️ Tech Stack
*   **Language:** Java
*   **Focus Area:** Arrays, Searching Algorithms, Pointer tracking, Array Rotations
